## Pipeline notes

- `tools/audio/fs_search.sh` / `fs_search_parse.py`: Freesound HTML search (CC0 filter), no login.
- `tools/audio/fs_fetch.sh` / `fs_sound_info.py`: saves each sound page, parses/verifies the license and downloads the HQ preview into its own batch directory under `.audio-src/raw/` (git-ignored).
- `tools/audio/analyze.py`: stats, hit detection/slicing helpers, spectrogram contact sheets, FFT pitch.
- `tools/audio/build.py tools/audio/recipe.json`: slices, cleans and masters everything, writes `public/audio/*.mp3`, `manifest.json` and `tools/audio/build_report.json`.
- `tools/audio/verify.py`: checks format, size budget, peaks, onsets and loop seams.
- `tools/audio/credits.py`: regenerates this file.
